# AI Speech Analyzer (Anti-Fraud) 🛡️🔊

Пет-проект для автоматического распознавания речи и анализа телефонных разговоров на предмет мошенничества.

## 🎯 Цели проекта
- Преобразование аудио в текст (STT) в реальном времени или из файла.
- Анализ текста на наличие признаков социального инжиниринга.
- Оценка рисков и выявление паттернов поведения мошенников.

## 🛠 Технологический стек
- **Язык:** Python 3.10+
- **STT Engine:** Faster-Whisper (OpenAI Whisper)
- **Audio Processing:** Pydub / FFmpeg
- **Analysis:** NLP / LLM (Gemini API)
- **UI:** Streamlit

## 🏗 Структура проекта
- `src/`: Исходный код (обработка аудио, транскрибация, анализ).
- `data/`: Примеры аудиофайлов для тестирования.
- `tests/`: Проверка логики работы приложения.
