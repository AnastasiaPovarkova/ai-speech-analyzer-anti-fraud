# AI Speech Analyzer (Anti-Fraud) 🛡️🔊

Интеллектуальный анализатор речи для выявления признаков мошенничества в телефонных разговорах. Проект использует оптимизированные модели для работы на локальном железе (Intel Mac) и семантический анализ текста.

## 🌟 Основные возможности

**Гибридная обработка:** Локальное распознавание речи (Whisper.cpp) + Облачный анализ (Gemini 3.1)
**Deep Analysis:** Использование модели gemini-3.1-flash-lite-preview для поиска психологического давления и подозрительных паттернов.
**Smart Audio:** Автоматическая подготовка аудио (16kHz, Mono) и удаление тишины для ускорения работы.
**JSON-вердикты:** Получение структурированных данных о степени риска, триггерах и рекомендациях.


## 🛠 Технологический стек
- **Язык:** Python 3.11
- **Движок распознавания:** `whisper-cpp` (Быстрое распознавание речи на CPU).
- **Библиотеки Python:** 
  - `pydub` — предварительная обработка аудио(конвертация, очистка тишины).
  - `google-genai` — интеграция с Gemini для анализа контекста.
- **Интерфейс:** Streamlit (планируется).

## 📦 Установка и настройка

### 1. Системные зависимости
Необходимы для распознавания и работы с аудио.

```bash
brew install whisper-cpp ffmpeg ffprobe
```

### 2. Подготовка модели Whisper
Для транскрибации используется модель формата GGML. Скачайте её в папку проекта:

```bash
mkdir -p models
curl -L [https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin) -o models/ggml-base.bin
```

### 3. Настройка окружения
```bash
# Создание и активация окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей Python
pip install -r requirements.txt
```

Создайте файл .env в корне проекта и добавьте ваш ключ:
```bash
GEMINI_API_KEY=ваш_ключ_из_google_ai_studio
```

## 🚀 Запуск 

Поместите аудиофайл (m4a, mp3, wav) в папку data/samples/
Запустите анализ:
```bash
python3 src/transcriber.py
```

Пример вывода системы:

## 🏗 Структура проекта
- `models/`: Файлы моделей Whisper (.bin).
- `src/transcriber.py`: Главный скрипт (оркестратор).
- `src/audio_processor.py`: Модуль очистки и подготовки звука.
- `src/ai_analyzer.py`: Интеграция с ИИ Gemini, анализ.
- `data/samples/`: Примеры аудиофайлов для тестирования (не загружаются в репозиторий).
- `tests/`: Проверка логики работы приложения.
