# AI Speech Analyzer (Anti-Fraud) 🛡️🔊

Интеллектуальная система защиты от телефонного мошенничества. Автоматически преобразует аудиозаписи в текст и анализирует их с помощью модели Gemini 3.1 Flash.

## 🌟 Основные возможности

- **Веб-интерфейс:** Простая загрузка аудио через браузер (Drag-and-Drop) или запись с встроенного диктофона.
- **Гибридная обработка:** Локальное распознавание речи (Whisper.cpp) + Облачный анализ (Gemini 3.1)
- **Deep Analysis:** Использование модели Gemini 3.1 Flash для поиска психологического давления, спама и подозрительных паттернов.
- **Smart Audio:** Автоматическая подготовка аудио (16kHz, Mono) и удаление тишины для ускорения работы.
- **База данных SQLite** - Сохранение результатов в историю, поиск по истории, удаление ненужных записей, экспорт всей истории анализа и отдельных проверок.
- **JSON-вердикты:** Автоматическое разделение звонков на 3 категории с подробным обоснованием вердикта:
- 🚨 МОШЕННИЧЕСТВО — попытки кражи данных, вымогательство, социальная инженерия, психологическое давление.
- ☎️ СПАМ — навязчивая реклама, звонки от роботов, соцопросы, предложения кредитов.
- 🤝 ЛИЧНЫЙ ЗВОНОК — безопасный бытовой или рабочий разговор.


## 🛠 Технологический стек
- **Язык:** Python 3.11
- **Frontend:** Streamlit
- **STT (Speech-to-Text):** Whisper.cpp (Быстрое распознавание речи на CPU).
- **Библиотеки Python:** 
  - `pydub` — предварительная обработка аудио(конвертация, очистка тишины).
  - `google-genai` — интеграция с Gemini для анализа контекста.
- **LLM:** Google Gemini 3.1 Flash Lite.
- **Database:** SQLite (локальное хранение истории).

## 🐳 Запуск через Docker
Использование Docker позволяет запустить приложение в полностью изолированном окружении. Вам не потребуется устанавливать компиляторы, ffmpeg или настраивать пути для whisper.cpp вручную — всё настроено внутри контейнера.

### 1. Подготовка окружения
Убедитесь, что у вас установлены Docker и Docker Compose. Создайте файл .env в корне проекта и укажите ваш API-ключ Gemini:
GEMINI_API_KEY=ваш_ключ_из_google_ai_studio

### 2. Сборка и запуск контейнера
Запустите сборку образа и старт контейнеров в фоновом режиме:
```bash
docker-compose up --build -d
```
При первой сборке Docker сам скачает все системные зависимости, скомпилирует whisper.cpp внутри контейнера и загрузит модель распознавания ggml-base.bin.

### 3. Использование приложения
Откройте браузер и перейдите по адресу:
```bash
http://localhost:8501
```

### 4. Полезные команды Docker
```bash
# Просмотр логов работы (транскрипции и ошибок):
docker-compose logs -f

# Остановка приложения:
docker-compose down
```

Сохранение данных: Папки data/ (база данных, аудиозаписи) и models/ (модели Whisper) смонтированы через volumes на вашу хост-систему. Это означает, что при обновлении или перезапуске контейнера ваша история звонков не сотрется.


## ⚙️ Локальная установка и настройка
Если вы хотите запустить проект непосредственно на вашем хост-компьютере, выполните следующие шаги:

### 1. Установка системных зависимостей (на примере macOS)
Необходимы для распознавания и работы с аудио.

```bash
brew install whisper-cpp 
brew install ffmpeg ffprobe
```

### 2. Клонирование репозитория и настройка окружения
```bash
git clone <url-вашего-репозитория>
cd ai-speech-analyzer-anti-fraud
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройка API
Создайте файл .env в корне проекта и добавьте ваш ключ:

```bash
GEMINI_API_KEY=ваш_ключ_из_google_ai_studio
```

### 4. Загрузка модели распознавания
Для транскрибации используется модель формата GGML. Скачайте её в папку проекта:

```bash
mkdir -p models
curl -L [https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin) -o models/ggml-base.bin
```

## 5. Локальный запуск

```bash
streamlit run app.py
```

Пример вывода системы:

