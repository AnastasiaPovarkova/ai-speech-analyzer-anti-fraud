# AI Speech Analyzer (Anti-Fraud) 🛡️🔊

Интеллектуальный анализатор речи для выявления признаков мошенничества в телефонных разговорах. Проект использует оптимизированные модели для работы на локальном железе (Intel Mac) и семантический анализ текста.

## 🚀 Функционал
- **Speech-to-Text:** Быстрая транскрибация аудио через движок `whisper-cpp`.
- **Fraud Detection:** Анализ текста на паттерны психологического давления и типичные фразы мошенников.
- **Reporting:** Оценка уровня угрозы и краткое резюме разговора через Gemini API.

## 🛠 Технологический стек
- **Язык:** Python 3.11
- **Движок распознавания:** `whisper-cpp` (высокая оптимизация под Intel CPU).
- **Библиотеки Python:** 
  - `pydub` — предварительная обработка аудио.
  - `google-generativeai` — интеграция с Gemini для анализа контекста.
- **Интерфейс:** Streamlit (планируется).

## 📋 Инструкция по развертыванию (macOS Intel)

### 1. Системные зависимости
Для работы проекта необходим движок `whisper-cpp` и утилита `ffmpeg`:

```bash
brew install whisper-cpp ffmpeg
```

### 2. Загрузка модели
Для транскрибации используется модель формата GGML. Скачайте её в папку проекта:

```bash
mkdir -p models
curl -L [https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin) -o models/ggml-base.bin
```

### 3. Настройка Python окружения
# Создание и активация окружения
```bash
python3 -m venv venv
source venv/bin/activate
```

# Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск транскрибации
Для теста распознавания речи используйте:
```bash
python3 src/transcriber.py
```

## 🏗 Структура проекта
- `models/`: Файлы моделей Whisper (.bin).
- `src/`: Исходный код (обработка аудио, транскрибация, анализ).
- `data/`: Примеры аудиофайлов для тестирования (не загружаются в репозиторий).
- `tests/`: Проверка логики работы приложения.
